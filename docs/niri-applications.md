# Программы из конфигурации niri

Проверены `~/.config/niri/config.kdl` и подключённый `dms/binds.kdl`.

| Команда | Источник в конфигурации |
| --- | --- |
| `firefox` | Системный модуль firefox |
| `ghostty` | Системный модуль terminal |
| `AyuGram` | Пользовательский модуль ayugram |
| `yazi` | Пользовательская часть модуля niri |
| `brightnessctl` | Системная часть модуля niri; добавлен по запросу для перехода с DMS |

DMS не устанавливается: принято решение перейти на другую оболочку.
Сейчас launcher — это `dms ipc call spotlight toggle`, а не отдельная
программа `applauncher`. Выбор его замены пока не сделан.

Текущие привязки launcher, громкости, яркости, управления проигрывателем,
уведомлений, буфера обмена и блокировки всё ещё вызывают DMS. Установка
brightnessctl сама по себе не переключает эти привязки. Файлы niri в /home
не изменены; их перенос и замена вызовов DMS остаются отдельным шагом.

Программы, упомянутые только в правилах сопоставления окон, не добавляются
автоматически: такие правила не запускают приложения.
